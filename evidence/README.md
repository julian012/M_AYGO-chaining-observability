# Evidencia

Aquí se guardan, ya curadas, las salidas que respaldan el paper: resúmenes JSON de `scripts/generate_load.py --out`,
capturas de una traza reconstruida, salida de `cfn-lint`, `pytest`, Trivy, etc.
El resto de `evidence/*` está ignorado por git para no versionar logs crudos. Usa `git add -f` solo para lo curado.
Nunca incluyas credenciales ni IPs/ARNs de la cuenta en capturas.
